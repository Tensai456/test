## สัญญา (ไฟล์ .mjs)
```js
export function decide(state, goal) {
  return null;                                   // ไม่มีความเห็น → ชิ้นถัดไปตัดสิน
  return { action: 'flee', thought: 'ข้อความที่จะโชว์ว่าคิดอะไร' };
}
```
- เรียก **5 ครั้ง/วิ/ตัว** ห้าม await · ถ้าต้องถาม Ollama ให้ยิง async แยก เก็บคำตอบล่าสุดไว้ แล้วคืนค่านั้น
- `state` = รูปแบบของ `mc-lab/lib/adapter/mineflayer_state.mjs` (hp, food, inv, nearby, flags, ...)
- ตัวอย่าง: `example_fly.mjs`

## กติกาผสม
1. มี `rules` ในชุด → reflex ด่วน (prio ≥50) และ veto ของกฎ **ชนะเสมอ**
2. ที่เหลือถามตามลำดับที่เขียน ชิ้นแรกที่ไม่คืน null ชนะ
3. ไม่มีใครตอบ → แผนของกฎ (ถ้ามี rules) · ไม่มี rules → `idle`

## ข้อจำกัดตอนนี้
- action จากสมองภายนอก **ยังไม่มีตัวลงมือ** (executor) — hub แค่โชว์/บันทึกว่าคิดอะไร · ท่าที่ลงมือจริงตอนนี้ = executor ค่าเริ่มของ mc-lab (ว่ายขึ้น หนีครีปเปอร์ ถือของกันตก กิน หยุดเมื่อชังก์ไม่โหลด) ที่ผูกกับ id กฎ
- ถ้าสมองเดิมเป็นโปรแกรมทั้งตัว (ไม่ใช่ฟังก์ชัน) → ทางเลือก: ให้โปรแกรมเดิมเขียน log ตามสคีมา แล้ว hub แค่อ่าน (ยังไม่ได้ทำ — ดู HANDOFF)
