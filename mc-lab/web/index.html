MC Duel Lab

จำลองการต่อสู้ Minecraft Java แบบวานิลลา คำนวณรายติ๊ก (20 tick/วินาที) มีฟิสิกส์เดิน วิ่ง กระโดด และกระเด็น พร้อม ping แต่ละฝั่ง ผลใช้เปรียบเทียบกลยุทธ์เท่านั้น ยังไม่ได้ยืนยันบนเซิร์ฟจริง

โอกาสรอด (Normal)

ค่าม็อบจากวิกิ (ระดับ Normal): ซอมบี้ตี 3, แมงมุมตี 2, โครงกระดูกยิง 3–5 ทุก 3 วิ, ครีปเปอร์ติดชนวนเมื่ออยู่ในระยะ 3 บล็อกและระเบิดหลัง 1.5 วิ (สูงสุด 43) ส่วนความเร็วม็อบและโอกาสยิงโดนเป็นค่าที่ตั้งเอง ยังไม่มีแหล่งอ้างอิง ระวังผลมือเปล่าสู้ซอมบี้หลายตัว ซึ่งตัวจำลองให้ผลสูงเกินจริง เพราะซอมบี้ล้อมจากด้านข้างไม่ได้

โค้ดชุดเดียวกับ mc-lab/lib ในแล็บ ฟิสิกส์ตรงกับตัวเลขวิกิ (วิ่ง 5.612 m/s, กระโดดสูง 1.2522 บล็อก, กระเด็นพื้นฐาน 1.552 บล็อก) ข้อจำกัด: จำลองแค่แกนเดียว ไม่มีการเดินอ้อมข้าง และใช้ค่า aim แทนการเล็งจริง
