# ไบโอมโอเวอร์เวิลด์และเนเธอร์ (Java vanilla) สำหรับบอตแล็บ
> W = https://minecraft.wiki/w/ · ข้อมูลจาก snippet ค้นหาเท่านั้น (โควต้าค้นหาหมดกลางทาง) · ช่องที่ไม่มีแหล่ง = [ไม่แน่ใจ] · คะแนนบ้าน 1-5 เป็นดุลยพินิจแล็บ ไม่ใช่ตัวเลขวิกิ

## plains-forest · ที่ราบ/ป่า (plains, forest, birch, dark forest)
| หัวข้อ | ข้อมูล |
|---|---|
| ไม้ | Plains: โอ๊คเกิดบางต้น 1/3 ใหญ่ 1/20 มีรังผึ้ง (W/Plains); Forest: โอ๊ค+เบิร์ช (W/Forest); Birch Forest ไม่มีโอ๊ค (W/Forest) |
| อาหาร | Plains: แกะ ไก่ หมู วัว (W/Plains) |
| ม็อบพิเศษ | Plains: ม้า/ลา (W/Plains); Forest: หมาป่า variant woods ตั้งแต่ 1.20.5; Birch/Dark Forest ไม่มีหมาป่า (W/Forest) |
| โครงสร้าง | Plains: หมู่บ้านไม้โอ๊ค, ด่านพิลเลเจอร์ (W/Plains) |
| Pale Garden | ตัวแปรหายากของ dark forest (W/Pale_Garden) |
| บ้าน | 4/5 ดุลยพินิจ: พื้นเรียบ ไม้/สัตว์หาง่าย (ไม่ใช่ข้อมูลวิกิ) |
- Forest ครอบ ~12% ของโอเวอร์เวิลด์ พบบ่อยสุด (W/Forest)
- ภัยเฉพาะไบโอม (ม็อบศัตรู/ค่า spawn ละเอียด) [ไม่แน่ใจ ไม่ได้ค้น]; Plains มี zombie horse กลางคืน (W/Plains)

บอตควร: ใช้เป็นฐานเริ่มต้น; ใช้ไม้โอ๊ค/เบิร์ชใน forest; ระวังหมาป่าแบบป่าถ้าโจมตี [ไม่แน่ใจ]
ตัดสินผล: เกณฑ์แล็บ ผ่านเมื่อบอตระบุไบโอมได้ถูกจาก F3/ข้อมูลเกม (ไม่ใช่ตัวเลขวิกิ)

## taiga-snowy · ไทกา/หิมะ (snowy taiga, grove, snowy slopes)
| ไบโอม | temp | หมายเหตุ | แหล่ง |
|---|---|---|---|
| Snowy Taiga | -0.5 | ป่าสนสปรูซปกคลุมหิมะ | W/Snowy_Taiga |
| Grove | -0.2 | ป่าสปรูซ พื้นหิมะ มี powder snow เป็นหย่อม | W/Grove |
| Snowy Slopes | -0.3 | หิมะหลายชั้น แถบ powder snow | W/Snowy_Slopes |
- powder snow เกิดตามธรรมชาติเฉพาะ grove, snowy slopes และห้อง trial chamber (W/Tutorial:Powder_snow_farming)
- หิมะตกคลุมบล็อกตามอุณหภูมิ ขึ้นกับความสูง (W/Snow)
- bogged โดน powder snow แล้วเสียหาย (W/Bogged)
- stray เกิดกลางคืน/พายุ ใน snowy plains, ice spikes, frozen ocean/river, snowy slopes, jagged peaks, frozen peaks แทน skeleton 80% (snowy plains/ice spikes); ยิงลูกศร slowness; ไม่แข็งใน powder snow (W/Stray)
- รองเท้าหนัง (leather boots) ทำให้เดินบน powder snow ได้ไม่จม และปีนได้ (W/Powder_Snow, W/Leather_Boots)
- ไม้/อาหารเฉพาะไบโอม [ไม่แน่ใจ]
- บ้าน 3/5 ดุลยพินิจ (ไม่ใช่ข้อมูลวิกิ): powder snow ติดกับดักได้ถ้าไม่มีรองเท้าหนัง

บอตควร: สวมรองเท้าหนังก่อนเดินบน powder snow (W/Powder_Snow); ระวัง stray ยิง slowness (W/Stray)
ตัดสินผล: เกณฑ์แล็บ ผ่านเมื่อบอตไม่ตกใน powder snow ในการทดสอบ

- มีไมซีเลียมและ mooshroom ที่นี่ที่เดียว; ไม่มีม็อบศัตรูเกิดตามปกติ (W/Mushroom_Fields)

- ข้อจำกัด: ทรัพยากรน้อย เกาะโดดเดี่ยวรอบมหาสมุทรลึก; ไม้ [ไม่แน่ใจ]
- บ้าน 4/5 ดุลยพินิจ (ปลอดภัยแต่ทรัพยากรน้อย) · ดู W/Tutorial:Best_biomes_for_homes

## unverified · ยังไม่ยืนยัน
- คะแนนบ้าน 1-5 ทุกกลุ่มเป็นดุลยพินิจ ไม่ใช่ข้อมูลวิกิ
- ชนิดไม้ที่เก็บได้ในจังเกิล (ยืนยันแค่ว่ามีต้นจังเกิล/โกโก้), นมแก้พิษ bogged, ม้า/ลาขี่ได้
- jagged/stony peaks รายละเอียด; อาหารรายไบโอม (taiga, desert, nether); ม็อบศัตรูเฉพาะ plains/forest
- การขนาด/ความหายากสัตว์ใน snowy biome (นอกจาก stray); beach/river ค่า spawn Java ละเอียด
- ตัวเลขทั้งหมดมาจาก snippet ไม่ได้เปิดหน้าเต็ม
