## stash · ฝากของ: อะไรเว้นไว้ติดตัว
- **ของสำหรับขุดเว้นไว้** (กติกา jing): อีเต้อ พลั่ว ขวาน คบเพลิง บันได นั่งร้าน
- เว้นไว้ด้วย: อาวุธ เกราะ ถังน้ำ/ไข่มุก (กันตก) อาหาร ≈20 แต้ม หินกรวด/ดิน 1 กอง (ถมทาง/ปิดลาวา)
- ที่เหลือฝากหีบตามหมวด (แร่ดิบ ของดรอปม็อบ ฯลฯ)

## tidy-area · ปรับพื้นรอบบ้าน/ในบ้านให้เรียบ
- เทียบความสูงพื้นจริงกับระดับพื้นบ้าน: สูงกว่า → ขุดออก · ต่ำกว่า → ถม · **เริ่มจากจุดใกล้บ้านที่สุด** แล้วขยายออกทีละรอบ ("ดีขึ้นเรื่อย ๆ")
- ข้ามจุดที่ต่าง >6 บล็อก (หน้าผา/หลุมลึก — ไม่ใช่งานเก็บบ้าน ตามกฎ jing บ้านต้องอยู่บนพื้นเรียบอยู่แล้ว)
- **เว้นพื้นที่สำหรับขุด** (กติกา jing): ปากเหมือง บันไดลงเหมือง หลุมที่ขุดอยู่ + ฟาร์ม → ส่ง `keep` ให้ tidyPlan · ถือว่าเรียบร้อยตามหน้าที่
- **เว้นทางเดินที่ขึ้นมาในบ้าน** (กติกา jing): ทางจากเหมือง/ใต้ดินขึ้นมาในบ้าน = `keep` ชนิด house-passage · ห้ามถม/ขุดเด็ดขาด (ปิดแล้วบอตกลับบ้านไม่ได้)
- ถมด้วยดิน/หินกรวดตามพื้นเดิม (ไม่ใช้ของมีค่า) · ถมรูรอบบ้านช่วยกันม็อบเกิดในที่มืดด้วย (kb/spawning/spawn-proofing)

ตัดสินผล: คะแนนพื้น (ช่องเรียบ ÷ ทั้งหมด ไม่รวมพื้นที่เว้น) ต้องไม่ลดลง · ถมปากเหมืองที่ใช้อยู่ = ผิด

## house-clean · เก็บกวาดในบ้าน (บล็อกที่บอตวางมั่ว + ของทิ้งพื้น — กติกา jing)
- ตอนบ้านเรียบร้อย: `bot.brain.snapshotHouse({x0,y0,z0,x1,y1,z1})` = จำแบบบ้าน (ในกล่องบ้าน)
- ตรวจ: `bot.brain.houseCheck()` → `stray` (บล็อกเกินในที่ที่ควรว่าง → ขุดออก เก็บเข้าหีบ) · `missing` (ผนัง/พื้นหาย → วางคืนชนิดเดิม) · `items` (ของตกพื้นในบ้าน → เก็บ แล้วจัดลงหีบตามหมวด)
- ของใช้ที่เพิ่มเองไม่นับว่ามั่ว: คบเพลิง ตะเกียง หีบ ถัง เตา โต๊ะคราฟต์ เตียง ป้าย กรอบ พรม กระถาง
- เป็นขั้นแรกของแผน home_keep (ไม่ใช่กฎฉุกเฉิน) · ทางเดิน/ประตูถูกขวาง = กฎ entrance-blocked แยก (ด่วนกว่า)
- แบบบ้านเปลี่ยน (ต่อเติม) → ถ่าย snapshot ใหม่หลังสร้างเสร็จ ไม่งั้นส่วนต่อเติมจะถูกนับเป็นบล็อกมั่วแล้วโดนรื้อ ⚠

ตัดสินผล: houseCheck ต้อง clean ภายในรอบว่างถัดไป (เกณฑ์แล็บ)

## passages · ทางเดินขึ้นบ้าน + ปากประตูต้องโล่งตลอด (กติกา jing)
- ปัญหาจริง: บอตวางบล็อก/ของขวางทางขึ้นบ้านหรือหน้าประตู → ทีมออกไม่ได้ → ต้องเช็กตลอด
- ลงทะเบียนช่องที่ต้องโล่ง: `bot.brain.setPassages([{x,y,z}, ...])` (ช่องเท้า — ต้องว่าง 2 ช่องสูง) · ปลั๊กอินเช็กทุก 20 tick (1 วิ)
- ผ่านได้: อากาศ ประตู ประตูกล ประตูรั้ว บันได นั่งร้าน คบเพลิง พรม แผ่นกด ปุ่ม ป้าย ราง (ไม่มีกล่องชนหรือเปิดได้)
- **กันก่อน:** `bot.brain.allowed('place_block', { pos })` บนช่องทางเดิน = veto (no-block-in-passage)
- **แก้หลัง:** เจอขวาง → กฎ entrance-blocked (prio 58 สูงกว่างานแผนทุกอย่าง แต่ภัยด่วนยังมาก่อน) → ขุดบล็อกที่ขวางออก

ตัดสินผล: ทางขึ้นบ้าน/ประตูถูกขวางนาน >10 วิ ขณะไม่มีภัย = ผิด (เกณฑ์แล็บ)

## torches · ปักคบเพลิงเพื่อไม่ให้ม็อบเกิด (กติกา jing)
- คบเพลิงแสง 14 ลด 1 ต่อบล็อก (ระยะ taxicab รวมแนวตั้ง) → ครอบคลุม 13 บล็อก · ม็อบศัตรูเกิดได้เฉพาะ block light 0 (+ sky light ≤7) (W/Light, W/Mob_spawning, W/Tutorial:Spawn-proofing)
- `torchPlan(heights, floorY, { torches, keep })`: ปูตาข่ายเพชร (เวกเตอร์ 13,14 / 14,−13 — ส่วนครอบปูเต็มพอดี 365 ช่อง/ดวง) แล้วเก็บตกจุดมืดที่เหลือ · ไม่รื้อดวงเดิม · ไม่ปักในพื้นที่เว้น
- **เขตบ้าน = รัศมี ≈100 บล็อก** (กติกา jing · `HOME_RADIUS`) → พื้นเรียบ 201×201 ต้องปัก **≈141 ดวง** = ถ่าน/ถ่านไม้ 36 + ไม้ 36 (คบเพลิง 1 สูตร = 4 ดวง) · คำนวณ 39 ms
- ทำทีละนิด: ใกล้บ้านก่อน (ตัวเก็บตกเรียงจากใกล้ไปไกล) · ถ่านไม่พอ → ทำถ่านไม้จากซุงในเตา (kb/progression/smelting-fuel)
- ตัวอย่างเล็ก: 41×41 (มีดวงกลางแล้ว) = 8 ดวง · 81×81 = 27 ดวง
- พื้นต่างระดับมาก → ต้องเพิ่มดวง (แสงลดตามความสูงด้วย) — ตัวเก็บตกจัดการให้
- ในบ้าน: ทุกห้องต้องมีคบเพลิง (ห้องปิดไม่มีแสงฟ้า = ม็อบเกิดในบ้านได้) [คิดเอง]

ตัดสินผล: ม็อบศัตรูเกิดในรัศมีที่ปักแล้ว = ตรวจว่ามีจุด block light 0 หลุด (เกณฑ์แล็บ)

## measure · วัดผลช่วงรอ
- `fitInWindow({ sort, tidy, waitSec })` → ช่วงรอทำได้กี่ท่า (เวลาต่อท่า = ASSUME: เปิดหีบ 1 วิ · ย้าย 1 กอง 1 วิ · ขุดดิน 0.5 · วาง 0.3 · เดิน 4.317 บล็อก/วิ จาก W/Walking)
- `createHomeMeter()` บันทึกต่อรอบ: เวลารอ · คะแนนจัดหีบ/พื้น ก่อน-หลัง · จำนวนท่า → `summary()` = คะแนนล่าสุด + คะแนนเพิ่มต่อนาทีรอ
- ใช้ตัวเลขจริงจากเซิร์ฟแก้ TIME ในโค้ด
