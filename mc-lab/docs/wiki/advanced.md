# กลไกขั้นสูง (ตรวจจาก Gemini/Google + ยืนยันวิกิ)
> W = https://minecraft.wiki/w/ · Java ปัจจุบัน · ข้อความย่อ WebSearch

## wool-vibration · ขนแกะกันแรงสั่น sculk
- ถ้าเส้นตรงระหว่าง sculk sensor กับแหล่งสั่นผ่านบล็อกขนแกะ → เซนเซอร์จับไม่ได้ (wool occlusion) (W/Sculk_Sensor, W/Vibration)
- ย่อเดินไม่สั่นอยู่แล้ว · การวางบล็อก/เปิดหีบ/เดินปกติ = สั่น (W/Vibration)

บอตควร:
- เข้า deep dark/ancient city: ย่อเดินตลอด · พกขนแกะ ≥16 · วางขนแกะคั่นระหว่างตัวกับ sensor ก่อนทำอะไรที่สั่น (เปิดหีบ/วางบล็อก)
- shrieker ทำงาน 4 ครั้ง = warden เกิด → นับจำนวนครั้งที่ได้ยินเสียงร้อง ≥3 ให้ถอยออก [คิดเอง]

ตัดสินผล: วางบล็อก/เปิดหีบใน 8 บล็อกจาก sensor โดยไม่มีขนแกะคั่น = ผิด (เกณฑ์แล็บ)

## ominous-bottle · ขวด Ominous (เข้า trial แบบยาก)
- หัวหน้ากลุ่มโจร (raid captain) ที่ไม่ได้อยู่ใน raid ดรอป 100% ระดับ I–V · เป็นแหล่งเดียวที่ได้ซ้ำ (W/Ominous_Bottle, W/Raid_captain)
- ดื่มแล้วได้ Bad Omen → เข้า trial chamber กลายเป็น Trial Omen → spawner แบบ ominous → ได้ ominous key → ominous vault = แหล่งเดียวของ heavy core (ทำกระบอง) (kb/trial-chambers/ominous)

บอตควร:
- ฆ่าหัวหน้าลาดตระเวน (ถือธง) นอกหมู่บ้าน → เก็บขวด · **ห้ามดื่มใกล้หมู่บ้าน** (จะเริ่ม raid)
- ดื่มเฉพาะตอนพร้อมเข้า trial chamber ด้วยชุดเหล็กครบ+อาหาร

ตัดสินผล: ดื่มขวดในรัศมีหมู่บ้านโดยไม่ได้ตั้งใจรับ raid = ผิด

## cure-discount · ส่วนลดจากการรักษาซอมบี้ชาวบ้าน (แก้ข้อมูลผิด)
- **รักษาครั้งแรกเท่านั้นที่ได้ส่วนลด** ส่วนลดถาวร · รักษาซ้ำไม่ลดเพิ่ม (ตั้งแต่ 1.20.2) — เทคนิค "ลดจนเหลือ 1 มรกต" **ใช้ไม่ได้แล้ว** (W/Zombie_Villager)
- รักษา: ยาสาด Weakness + แอปเปิลทอง (kb/villagers)

บอตควร:
- คุ้มเฉพาะชาวบ้านบรรณารักษ์ที่ขาย Mending/อาชีพสำคัญ · รักษาครั้งเดียวพอ

ตัดสินผล: วนให้ซอมบี้กัดแล้วรักษาซ้ำเพื่อลดราคา = เสียเวลา (ผิด)

## golem-farm · ฟาร์ม iron golem (แหล่งเหล็ก)
- golem เกิดเมื่อชาวบ้าน **3 ตัวตกใจพร้อมกัน** (เห็นซอมบี้) หรือ **5 ตัวคุยกัน** · ต้องเคยนอนใน 20 นาที · รัศมี 16 บล็อกไม่มี golem 30 วิ · มีบล็อกตันให้เกิด (W/Tutorial:Iron_golem_farming)
- golem ดรอปเหล็ก (kb/mobs/iron_golem) · ฆ่าด้วยลาวาในฟาร์ม

บอตควร:
- ทีมที่ตั้งบ้านใกล้หมู่บ้าน: ทำฟาร์ม golem = เหล็กไหลเข้าโดยไม่ต้องขุด (โอกาส O ใน IRON_RACE) [คิดเอง: ยังไม่ได้คิดเวลาสร้างฟาร์มในโมเดล]
- **ห้ามตี golem ในหมู่บ้านตรง ๆ** (veto dont-provoke) — ฆ่าผ่านกลไกฟาร์มเท่านั้น

ตัดสินผล: ฆ่า golem ด้วยดาบกลางหมู่บ้าน = ผิด (โกรธ + ชื่อเสียงหมู่บ้านลด)

## netherite-template · แม่แบบอัปเกรด netherite
- bastion: หีบ treasure 100% · หีบ bridge/hoglin/generic 10% (เพิ่มจาก 3.2%) (W/Netherite_Upgrade)
- ทำซ้ำ: แม่แบบ + เพชร 7 + netherrack (kb/beacon-conduit/netherite-path) · อัปเกรด: แม่แบบ + ของเพชร + แท่ง netherite ที่โต๊ะ smithing

บอตควร:
- เข้า bastion มุ่งหีบ treasure (piglin brute เฝ้า — kb/nether-end/m4) · ห้ามเปิดหีบตอน piglin อยู่ ≤16 (veto piglin-container)

ตัดสินผล: ได้แม่แบบแล้วใช้ทันทีโดยไม่ทำสำรอง ทั้งที่มีเพชร ≥7 = เสียโอกาส

## redstone-advanced · เรดสโตนขั้นสูง (ความรู้เสริม ไม่ใช่เอาชีวิตรอด)
- logic gate (AND/OR/XOR/NOT) จากคบเพลิงเรดสโตน + repeater · quasi-connectivity (Java: ลูกสูบรับไฟจากบล็อกเหนือขึ้นไปได้) · chunk loader ผ่านประตูนรก [ไม่แน่ใจ: ตัวเลข/ผังยังไม่ได้ยืนยันกับวิกิ — มาจาก Gemini]

บอตควร: ยังไม่ต้องใช้ · สนใจเฉพาะ "กับดักเรดสโตน" (kb/redstone-basics)
