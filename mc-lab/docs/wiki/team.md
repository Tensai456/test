# ทีมบอต 4 ตัว (เกณฑ์แล็บ + วิกิ)

> W = https://minecraft.wiki/w/ · ส่วนใหญ่เป็นกติกาทีมที่แล็บตั้งเอง [คิดเอง] · ค่าจากเกมระบุแหล่ง

## food-share · แบ่งอาหาร
- อาหารตกพื้นหายใน 6000 tick (5 นาที) ถ้าชังก์โหลดอยู่ (W/Item_(entity))
- กฎทีม: เพื่อนหิว <6 ในระยะ 32 + เรามีอาหาร + ไม่มีศัตรู ≤6 → โยนให้ครึ่งหนึ่ง (เก็บไว้เองอย่างน้อย 1 ชิ้น) [คิดเอง]

บอตควร: โยนของตรงหน้าเพื่อน ≤3 บล็อก (ของไหลไกลหาย/ตกเหว) · ห้ามโยนตอนมีม็อบ

ตัดสินผล: เพื่อนอดตายขณะที่เรามีอาหาร ≥4 ชิ้น = ผิด

## role-swap · เพื่อนตาย → รับบทแทน
- ของเพื่อนกองอยู่ 5 นาที (W/Item_(entity)) → ตัวที่ใกล้สุดไปเก็บถ้าปลอดภัย
- เพื่อนเป็นนักขุด (miner) → ตัวที่มีอีเต้อดีที่สุดรับบทนักขุดแทน [คิดเอง]

บอตควร: ประกาศในแชตทีม "รับบท X" ก่อนเปลี่ยน (กันสองตัวแย่ง) [คิดเอง]

ตัดสินผล: ไม่มีใครรับบทนักขุดเกิน 2 นาทีเกม หลังนักขุดตาย = ผิด

## ore-claim · แย่งแร่สายเดียวกัน
- กฎทีม: ตัวแรกที่เห็นสายแร่ "จอง" (ธง oreClaimed ให้ตัวอื่น) · ตัวอื่นห้ามขุดสายนั้น ให้ไปหาสายใหม่ [คิดเอง]
- เหตุผล: ขุดพร้อมกันตรงเดียว = เสียเวลาเดิน + ตีโดนกัน + กองของปนกัน

ตัดสินผล: สองบอตขุดสายเดียวกันพร้อมกัน = ผิด (veto ore-claimed)

## team-sleep · นอนพร้อมกัน
- เซิร์ฟผู้เล่นหลายคน: ข้ามคืนได้เมื่อผู้เล่นนอนครบตาม gamerule players_sleeping_percentage (ค่าเริ่ม 100%) (W/Game_rule) [ไม่แน่ใจ: ค่าที่เซิร์ฟ s39 ตั้งไว้]
- บอตที่ไม่นอน = ทำให้ทั้งทีมต้องอยู่กลางคืน (phantom หลัง 3 คืนไม่นอน — kb/time-weather/phantom)

บอตควร: ถึงเวลานอน (12542+) ทุกตัวกลับเตียง · ตัวที่อยู่ไกล >200 บล็อกแจ้งทีม [คิดเอง]

## pvp-bots · PvP ระหว่างบอต (กฎแล็บ jing)
- **ห้ามชนะด้วยการทิ้งอาวุธ** · **ห้ามขังตัวเองในกำแพงเพื่อชนะ**
- crit ได้เฉพาะตอนตก + ไม่วิ่ง + ชาร์จ ≥84.8% (kb/weapons/melee) · ใช้อาวุธจาก bestWeapon (kb/sim/pvp-results)

ตัดสินผล: ทิ้งอาวุธ/ขังตัว = แพ้ทันทีตามกฎแล็บ
