# ที่หลบภัยและม็อบที่ทุบบล็อกได้ (กฎ jing + วิกิ)

> W = https://minecraft.wiki/w/ · ข้อความย่อจาก WebSearch · กฎ jing (7 ต.ค. 2026): **ทำที่หลบได้** แต่ต้องรู้ว่าม็อบไหนทุบบล็อกได้ · ต้องพยายามหลบ · ต้องหาของมาจัดการมันให้ได้

## shelter-rule · กฎที่หลบ (jing ยืนยัน)
- ที่หลบคืนแรก / หลบเข้าบ้านหนี ravager = **ทำได้** (ไม่นับเป็น "ขังตัวเอง") · กฎ "ห้ามขังตัว" ใช้กับการขังตัวเพื่อชนะ PvP (kb/team/pvp-bots)
- ที่หลบไม่ได้แปลว่าปลอดภัย 100% → ต้องเช็กม็อบที่ทุบบล็อกได้ (หัวข้อถัดไป) ตลอดเวลา

บอตควร: สร้างที่หลบด้วย **หินกรวด (cobblestone)** ไม่ใช่ดิน · ไม่นอนนิ่งรอเช้าแบบไม่ดู — สแกนม็อบรอบตัวทุก tick เหมือนอยู่ข้างนอก

ตัดสินผล: ที่หลบทำจากดิน/ทราย ทั้งที่มีหินกรวด ≥20 = ผิด (เกณฑ์แล็บ)

## block-breakers · ม็อบที่ทุบ/เปลี่ยนบล็อกได้
| ม็อบ | ทำอะไรกับบล็อก | แหล่ง |
|---|---|---|
| ครีปเปอร์ | ระเบิด พลัง 3 (ชาร์จ 6) | W/Creeper |
| ซอมบี้ (+ vindicator) | พังประตูไม้ — เฉพาะ Hard (kb/advanced/regional-difficulty) | W/Zombie |
| enderman | หยิบ/วางบล็อกใน tag enderman_holdable (ดิน, หญ้า, มอส, โคลน, ดอกไม้, กระบองเพชร, ฟักทองแกะ, ดินเหนียว ฯลฯ 23 ชนิด) — **หยิบหินกรวดไม่ได้** | W/Enderman, W/Block_tag_(Java_Edition) |
| ghast | ลูกไฟระเบิดพลัง 1 + จุดไฟ · บล็อกต้านแรงระเบิด ≥3.5 รอด | W/Fireball, W/Ghast |
| Wither | ระเบิดตอนเกิด + หัวกะโหลกระเบิดบล็อก | W/Wither |
| มังกร | ทำลายบล็อกที่บินชน | W/Mob_griefing |
| ravager | พังใบไม้ทุกชนิด + พืชบางชนิด (Java) | W/Ravager |
| silverfish | มุดเข้าบล็อกหิน (infested) | W/Mob_griefing |
- ทั้งหมดปิดได้ด้วย gamerule mob_griefing (W/Game_rule) [ไม่แน่ใจ: เซิร์ฟ s39 ตั้งไว้อย่างไร]

บอตควร: อ่าน mob_griefing ของเซิร์ฟก่อนเริ่ม (ถ้าปิด → ที่หลบใด ๆ กันได้เกือบหมด)

## blast-resistance · บล็อกกันระเบิด
| บล็อก | ต้านแรงระเบิด | กันอะไรได้ | แหล่ง |
|---|---|---|---|
| ดิน | 0.5 | ไม่กันอะไรเลย | W/Explosion |
| หินกรวด | 6 | ลูกไฟ ghast (ต้องการ ≥3.5) · ครีปเปอร์ทำรูได้ | W/Cobblestone, W/Fireball |
| obsidian | 1,200 | ครีปเปอร์/ชาร์จ/Wither (ระเบิดทั่วไป) | W/Obsidian |
- [ไม่แน่ใจ: ครีปเปอร์พลัง 3 ทำลายหินกรวดได้กี่บล็อก — ขึ้นกับระยะ/สุ่ม]

บอตควร: ผนังที่หลบ = หินกรวดขึ้นไป · ในนรกห้ามใช้ netherrack (ต้าน 0.4 [ไม่แน่ใจ]) ทำกำแพงกันลูกไฟ → ใช้หินกรวด

## counter-each · หลบ + หาของจัดการ (ทีละตัว)
| ภัย | หลบยังไง | ของที่ต้องหามาจัดการ |
|---|---|---|
| ครีปเปอร์ข้างกำแพง | ได้ยินเสียงฟ่อ → ถอยไปฝั่งตรงข้ามของที่หลบ ≥4 บล็อก [คิดเอง] | ธนู (ยิงก่อนเข้าใกล้) · ซ่อมรูด้วยหินกรวดทันที |
| ซอมบี้ตีประตู (Hard) | ยืนห่างประตู ตีผ่านช่อง | **ประตูเหล็ก + ปุ่ม/คันโยก** (เหล็ก 6 ก้อน) |
| enderman ดึงบล็อก | ห้ามมองตา · ผนังหินกรวดกันได้ | ฟักทองแกะสวมหัว (กันโกรธจากการมอง) · ดาบ |
| ghast ยิงที่หลบ | อยู่หลังหินกรวด · เห็นลูกไฟ → ตีสะท้อนกลับ | ธนู · หินกรวดสำรอง ≥32 ในนรก |
| ravager | **เข้าบ้าน/ช่อง 1 บล็อก** (ravager กว้าง 2 เข้าไม่ได้ ตีไม่ถึง) · ห้ามทำที่หลบด้วยใบไม้ | ดาบ/ขวาน ตีจากข้างใน · โล่ |
| Wither | อย่าหลบในที่หลบ — ระเบิดทะลุ → **ออกไปสู้ใต้ดิน/หนี** | ดาบ Smite · ยา Regeneration · นม (ล้าง Wither) |
| silverfish (stronghold/ภูเขา) | ไม่ขุดบล็อกหินที่ขุดเร็วผิดปกติ [คิดเอง] | ดาบ · ลาวา/กรวด |

ตัดสินผล: ที่หลบโดนเจาะแล้วบอตอยู่นิ่ง >2 วิ ไม่ซ่อม/ไม่ถอย = ผิด (เกณฑ์แล็บ)

## scaffold-clutch · นั่งร้านกันตก ("Follow" = Scaffold)
- **ย่อ (sneak) ตอนตกลงบนนั่งร้าน = ไม่เสียเลือด** · ตกจากที่สูงมากต้องเป็นนั่งร้านซ้อน **≥2 ชั้น** · ชั้นเดียวกันได้เฉพาะความสูงน้อย (W/Scaffolding, W/Tutorial:Breaking_a_fall)
- [ไม่แน่ใจ: "ความสูงน้อย" กี่บล็อก — วิกิไม่ระบุในสรุป]

บอตควร: ใช้นั่งร้านกันตกได้เมื่อ (1) กดย่อค้าง (2) ตกไม่สูงมาก หรือวางล่วงหน้า 2 ชั้นไว้แล้ว · ตกสูงมาก + มีแค่นั่งร้าน → ไข่มุก/ถังน้ำก่อน
- ⚠ โค้ด `chooseClutch` ตอนนี้เลือกนั่งร้านได้ทุกความสูง → ต้องแก้ตอนเริ่มจำลองรอบใหม่ (บันทึกไว้ ยังไม่แก้ตามคำสั่ง "เก็บวิกิก่อน")

ตัดสินผล: วางนั่งร้านชั้นเดียวกันตกจาก >24 บล็อก [ไม่แน่ใจ: เกณฑ์] โดยมีถังน้ำ = เลือกผิด
