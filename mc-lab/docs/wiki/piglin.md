# Piglin — ทำให้ไม่โกรธ / อะไรทำให้โกรธ / แลกของ
> W = https://minecraft.wiki/w/ · จากข้อความย่อ WebSearch (ไม่ได้เปิดทั้งหน้า) · Java ปัจจุบัน

## calm · ทำให้ไม่โกรธ
- piglin เป็นม็อบเป็นกลางที่ **โจมตีผู้เล่นเสมอ ยกเว้นใส่ชุดทองอย่างน้อย 1 ชิ้น** (W/Piglin)
- กฎ jing: ทองทำ**รองเท้า**เท่านั้น → ใส่รองเท้าทองก่อนเข้านรกทุกครั้ง
- piglin brute **ไม่สนทอง** — โกรธเสมอ (W/Piglin_Brute)

บอตควร:
- ก่อนเข้าพอร์ทัล: เช็กว่าใส่ `golden_boots` อยู่ (ไม่ใช่แค่มีในกระเป๋า)
- เห็น brute → ถือว่าศัตรูเสมอ ไม่ต้องพึ่งทอง

ตัดสินผล: เข้านรกโดยไม่ได้ใส่ทอง = ผิดทันที

## anger · อะไรทำให้โกรธ
- เปิด/ทุบ หีบ, หีบกับดัก, หีบทองแดง, หีบเอนเดอร์, กล่อง shulker, ถังไม้ (barrel), รถรางมีหีบ, เรือมีหีบ (W/Piglin)
- ขุดบล็อกทอง / แร่ทอง / gilded blackstone → piglin ในรัศมี **16 บล็อก** โกรธพร้อมกัน **ไม่ต้องเห็นตัวเรา** (W/Piglin)
- ตี piglin → ตัวรอบ ๆ โกรธทั้งกลุ่ม (W/Piglin)

บอตควร:
- ห้ามเปิดหีบ/ขุดทองถ้ามี piglin ในระยะ 16 บล็อก (veto `piglin-container`) — ล่อให้ห่างก่อน หรือเคลียร์ให้หมดก่อน
- ห้ามตี piglin ที่ยังไม่โกรธ (veto `dont-provoke`)

ตัดสินผล: เปิดหีบ/ขุดทองใกล้ piglin ≤16 แล้ว piglin โกรธ = ผิด

## barter · แลกของด้วยทอง
- โยนทองแท่งให้ piglin ผู้ใหญ่ → มันดู 6–8 วินาที แล้วทิ้งของสุ่มจากตาราง (W/Piglin, W/Tutorial:Bartering_farm)
- ของที่ piglin ชอบ: ทองแท่ง, ก้อนทอง, บล็อกทอง, แร่ทอง, แอปเปิลทอง, ขวานทอง, นาฬิกา ฯลฯ (W/Piglin)
- ของที่ได้จากการแลก (ไข่มุก/ยากันไฟ/obsidian) [ไม่แน่ใจ: อัตราแต่ละชิ้นยังไม่ได้ค้น]

บอตควร:
- มีทองเหลือ → แลกกับ piglin ระหว่างรอ (ได้ไข่มุก/ยากันไฟ ช่วยแผน End) [คิดเอง]
- อย่าทิ้งทองที่อยากเก็บไว้ใกล้ piglin (มันจะเก็บไป) [ไม่แน่ใจ]

ตัดสินผล: (เกณฑ์แล็บ) แลกทอง 1 แท่ง ได้ของภายใน 10 วิ = ถูก
