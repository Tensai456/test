## 1. กลไกกลางที่ทุกอาวุธใช้ร่วมกัน
| เรื่อง | ค่า | แหล่ง |
|---|---|---|
| cooldown (tick) | 20 ÷ attack speed · ดาบ 1.6 → 12.5 tick · ขวานเหล็ก 0.9 → 22 · ขวานเพชร/เนเธอไรต์ 1.0 → 20 · กระบอง 0.6 → 33 | WC §1 · KB-attack-speed |
| ตัวคูณดาเมจตามชาร์จ | 0.2 + p² × 0.8 (p = ส่วนที่ชาร์จ) — สูตรนี้อยู่ในโค้ด lib/pvp/damage.mjs แต่วิกิรอบนี้ยังไม่ได้ยืนยันสูตร | KB-attack-speed ([ไม่แน่ใจ] สูตรสเกลเต็ม) |
| ตีให้นับ (คริ / sprint-KB / sweep) | ต้องชาร์จ ≥ 84.8% | VM §5 · KB-sweep-knockback |
| **คริ** | ต้อง "ตก" (กระโดดแล้วตีขาลง) + **ไม่วิ่ง** + ชาร์จ ≥ 84.8% → ×1.5 · หอกคริไม่ได้ | VM §5 · docs/wiki/version-26x.md (หอก) · lib/pvp/damage.mjs |
| sprint-knockback | ตีตอนวิ่ง = KB เพิ่ม + ยกเลิกวิ่ง · ใช้พร้อมคริ/sweep ไม่ได้ | KB-sweep-knockback |
| knockback | ฐาน 1.552 บล็อก · +2.586/เลเวล Knockback · sprint ≈ +1 เลเวล (จำลอง 4.31 vs วิกิ 4.138, คลาด ~4%) | SR §1 · lib/pvp/kb_model.mjs |
| i-frames | 10 tick หลังโดน — ช่วงนั้นโดนได้เฉพาะส่วนที่เกินครั้งก่อน → ตีโดนสูงสุด 2 ครั้ง/วิ | lib/pvp/damage.mjs · best_weapon.mjs |
| เกราะ | dmg × (1 − eff/25), eff = min(20, max(armor/5, armor − dmg/(toughness/4+2))) · เหล็กเต็มชุด armor 15 | lib/pvp/damage.mjs, weapons.mjs |
| **W-tap** | ตีแล้วปล่อย W แล้วกดวิ่งใหม่ → ทุกฮิตได้ sprint-knockback · วิกิ PvP มีคำนี้ ("sprint-reset") | W/Tutorial:PvP_(Java_Edition) (ค้นรอบนี้) · VM §5 |
| **S-tap** | แตะ S หลังตีโดน เพื่อถอยออกจากช่วงตีกลับและรักษาระยะคอมโบ | W/Tutorial:PvP_(Java_Edition) (ค้นรอบนี้) |
| strafe | กด A/D ค้างวนรอบเป้าระหว่างคอมโบ · ยิงธนูให้ strafe ซ้าย-ขวาเพื่อหลบ | W/Tutorial:PvP_(Java_Edition) · VM §5 |
| ผลตีโดน | ผู้ตีหยุดวิ่ง + ความเร็วแนวนอนเหลือ 60% | VM §5 (W/Melee_attack) |
| ความเร็ว | วิ่ง 5.612 · เดิน 4.317 บล็อก/วิ · วิ่ง+กระโดดเฉลี่ย 7.127 | VM §1 |

**ข้อควรระวัง w-tap:** ตัวจำลองให้ "ชาร์จเต็ม+w-tap" แพ้ชาร์จเต็มธรรมดา 27% vs 59% (SR §2) แต่ SR ระบุว่าเป็นข้อจำกัดของแบบ 1 มิติ → **ห้ามใช้ตัดสินเลิก w-tap** รอเทสจริง. ผู้เล่น jing ใช้ "ยืนห่าง ~3.8 บล็อกแล้วกระโดดคริ ~30%" (brief §1) ไม่ได้บอกว่า w-tap.

### ไข่มุกหนี (pearl escape) — ขั้นตอน [คิดเอง บนตัวเลขข้างต้น]
1. HP ≤ 8 (4 หัวใจ) และ HP > 5 (วาร์ปเสีย 5) — ถ้า HP ≤ 5 ห้ามปา เสี่ยงตายเอง
2. ปาไปทิศตรงข้ามเป้าและไม่ใช่ห้วงตกสูง/ลาวา
3. หลังลง: กินแอปเปิลทอง (1.6 วิ) ก่อนกลับไปสู้
4. ตรวจผลภายใน 5 วิ: ระยะห่างจากเป้า > 15 บล็อก [เกณฑ์แล็บ ตั้งเอง]
