# EVENT_INVENTORY — เหตุการณ์ที่เทสแล้ว · ช่องโหว่ที่ปิดแล้ว · ที่ยังไม่ได้เทส

> ใช้ให้ jing ช่วยคิดว่ายังขาดอะไร ก่อนเริ่ม chain รวมทุกอย่าง · ตัวเลข = จำลองเท่านั้น
> กติกา: ทุกเหตุการณ์ ≥2,000,000 ตัวอย่าง (รอบละ 200,000 seed ใหม่) → เจอช่องโหว่ = ปิด → รันต่อ · ยังเจอ → เพิ่มทีละ 200,000 ถึง 10,000,000

## 3. ยังไม่ได้เทส — ช่วยคิดว่าต้องเพิ่มอะไร

| raid | ตั้งรับแต่ละ wave · evoker/vex/ravager · ปกป้องชาวบ้าน | ✅ hazards/raid, villagers/raid |
| บอส | มังกร (คริสตัล/ลมหายใจ/เกาะแท่น) · Wither (สร้าง/สู้) | ✅ nether-end/d3, wither |
| trial chamber | spawner หลายคลื่น · breeze · ominous | ✅ trial-chambers/* |
| โครงสร้างกับดัก | พีระมิด TNT · วัดป่า tripwire · ancient city · monument | ✅ structures/*, redstone-basics/* |
| การเดินทาง | เรือ/รถราง/ม้า · เอลิทรา (ชนกำแพง/ร่อนลง) · Riptide | ✅ travel/*, elytra/* |
| ทีม | แบ่งอาหาร · เปลี่ยนบทบาทเมื่อเพื่อนตาย · แย่งแร่สายเดียวกัน · นอนพร้อมกัน | ⚠ บางส่วน (teammate-down, roles) |
