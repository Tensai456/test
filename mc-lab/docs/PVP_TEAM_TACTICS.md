## 2. บทบาทต่อชุด (สมมติฐานจากสถิติ 1v1 ใน PB §5)
| ชุด | บทบาท | เหตุผล/ตัวเลข |
|---|---|---|
| ดาบเหล็ก (100% vs OldSpar) | **ตัวหลักประชิด / รับเป้า** | สถิติสูงสุด; DPS คริ 14.4/วิ |
| ขวาน (~80%) | **ตัวเปิดโล่** | ปิดโล่ 5 วิ; DPS ต่ำกว่าดาบ 8.1 vs 9.6 |
| ธนู (67%) / ดาบ+ธนู (~80%) | **ตัวยิงหลัง** | 6–11 ต่อลูก ไกล >6 บล็อก |
| กระบอง+ลูกลม (เดี่ยว 8–25%) | **ตัวปิดเกม** ทุบเมื่อมีช่อง ไม่ใช่ตัวหลัก | สัดส่วนดาเมจสูง (54% ของ jing) แต่ 21% ของการตี |
| หน้าไม้/ตรีศูล (~50%) | ตัวรอง / ตัวกวนระยะ | ชนะครึ่งเดียว |
| หอก (0%) | **ห้ามเป็นตัวหลัก** จนกว่าจะทดสอบ | charge ต้องเข้าหากัน ≥4.6 บล็อก/วิ |

## 3. สถานการณ์
### 3.1 2v1 (เรา 2 ตัว vs 1)
1. **เป้าเดียว ไม่แยก:** ทั้งสองเลือกเป้าเดียวกัน (§4) · A เป็นตัวหน้า (ดาบ), B ขนาบข้าง
2. **ฮิตสลับจังหวะ:** A ตีที่ t=0, B ตีที่ t≥10 tick (พ้น i-frames) → ดาเมจสะสมเต็มทั้งสองฮิต [คิดเอง บนกลไก i-frames]
3. **ถ้าเป้ายกโล่:** คนขวานตีโล่ก่อน (ปิด 100 tick) แล้วอีกคนเข้าตีทางข้าง/หลัง (โล่คุม 180° ด้านหน้า — ด้านหลังเป้าบล็อกไม่ได้ KB-shield)
4. **ถ้าเป้าหนี:** ห้ามไล่ทั้งคู่ — คนถือธนู/เบ็ดตาม (เบ็ดดึงกลับ WC §5) อีกคนไม่หลุดจากเพื่อน
5. **เมื่อ HP ฝ่ายเราตัวใดต่ำ (≤8):** ตัวนั้นถอยกิน/ไข่มุก อีกตัวรับเป้า (ไม่ทิ้งเพื่อน)

### 3.2 2v2
1. **เลือกคู่ต่อสู้ตัวเดียวก่อน** (focus fire §4) → ตัวที่เหลือของเราใช้ B ขนาบให้ศัตรูตัวที่สองไม่ช่วยได้
2. ตัวหลังเรา (ธนู) ยิงตัวที่เรากำลังรุม หรือยิงตัวที่สองเพื่อกดดันไม่ให้ช่วย
3. พอตัวแรกตาย → 2v1 ตาม §3.1
4. แยกกันสู้ (1v1 สองคู่) เป็นทางเลือกสุดท้าย — เมื่อสถิติ 1v1 ของเรา ≥ ศัตรูทั้งคู่ (PB §5)

### 3.3 ขนาบ (flanking)
- เป้าอยู่ในมุมโล่ 180° ด้านหน้า (KB-shield) → ตัวหนึ่งเข้าหน้า อีกตัวอ้อมไปด้านหลัง/ข้าง (ระยะวง ≥3 บล็อก เพื่อไม่ถูกเป้าหันตีง่าย [คิดเอง])
- circle strafe (W/Tutorial:PvP_(Java_Edition)) สลับทิศทุก ~1–2 วิ (เกณฑ์แล็บ [คิดเอง]) — ใช้ตอนขนาบเพื่อให้เป้าหันไม่ทัน
- ข้อควรระวัง: ห้ามวางบล็อกขังเป้า-ขังตัวเอง; ใยแมงมุมขังศัตรูเท่านั้น (WC §3) ห้ามตัวเองติด

### 3.4 ล่อ (baiting)
| อุบาย | ทำงานเพราะ | แหล่ง |
|---|---|---|
| ให้เป้าแกว่งขวานใส่โล่เรา | ขวาน cooldown 22 tick — หลังแกว่งเป็นช่องสวน | WC §1 |
| ล่อกระบองให้กระโดดแล้วพลาด | ทุบพลาด = โดนดาเมจตกเอง + cooldown 33 tick | PB §2.3 · weapon_tactics.mjs |
| ล่อให้เป้าง้างธนู/หน้าไม้ค้างแล้วเข้าประชิด | ง้าง 0.9–1.25 วิ ไม่ขยับ | KB-ranged-weapons |
| ล่อหอกให้ charge ใส่เป้าที่ถอย | closing ≤ 1.3 บล็อก/วิ → ไม่มีดาเมจ | PB §2.7 · WC §5 |
| ล่อให้ลอยจากลูกลมแล้วถอยให้ตกเอง | ต้องหลบแนวนอน ≥3 บล็อก [คิดเอง] | WC §4 |
ทั้งหมดเป็น [คิดเอง] ยกเว้นตัวเลข cooldown. อย่าใช้ล่อด้วยการ "ทิ้งอาวุธ" (ผิดกฎแล็บ).

## 4. เลือกเป้า (target selection) — ลำดับตัดสิน [คิดเอง บนข้อมูลแล็บ]
1. **ผู้ที่ HP ต่ำสุด + ใกล้ที่สุด** → จบเร็ว ลดจำนวนศัตรู
2. **ผู้ถือกระบอง/ธนู (ดาเมจต่อครั้งสูง)** ที่อยู่ในระยะ เพราะ jing ระบุกระบอง 54% ของดาเมจ — ทำลายตัวทำดาเมจก่อน
3. ผู้ถือหอก = ให้ความสำคัญต่ำ (สถิติ 0%)
4. ผู้ยกโล่ = ให้ตัวขวานจัดการ ตัวอื่นเลี่ยง
5. ห้ามเปลี่ยนเป้ากลางคอมโบ ถ้าเป้าเดิม HP ต่ำกว่าอีกตัว (focus fire)
**ตัดสินผล:** ใน 20 วิหลังเริ่ม ถ้าเป้า A ยังไม่ลด HP ≥50% → ทบทวนเลือกเป้า [เกณฑ์แล็บ ตั้งเอง]

## 5. ตารางแก้ทางรายคู่ต่อสู้ (จากสถิติใน PB §5)
| ฝ่ายตรงข้าม | สถิติที่รู้ | ทีมทำ |
|---|---|---|
| ดาบเหล็ก (เก่งสุด 100%) | บอตชนะ 100% | ประชิดดาบ+โล่ ยกค้าง; อย่า 1v1 กับตัวนี้ถ้าเราเป็นหอก/กระบองเดี่ยว |
| ดาบ+โล่ | ขวาน vs ดาบ+โล่ = 66% (SR) | ส่งขวานเปิดโล่ คนอื่นตามเข้า |
| ธนู/หน้าไม้ | ธนู 67%, หน้าไม้ ~50% | ยกโล่ (ธนู), เข้าประชิดซิกแซก; ตัวธนูของเรายิงสวน |
| กระบอง+ลูกลม | สัดส่วนดาเมจสูง | ห้ามยืนใต้ตัวมัน; ถอยแนวนอน; ตีตอนมัน cooldown 33 tick |
| ตรีศูล | ~50% | ขว้างแล้วเข้ารุก; ระวังพายุ (13) |
| หอก | 0% | ไม่ต้องกลัว charge ถ้าไม่วิ่งเข้าหา; หลบเข้าประชิด <2 บล็อก |
| ผู้เล่นจริง (jing: ยืน ~3.8 บล็อก + กระโดดคริ ~30%) | ข้อมูลคนจริง | ปิดระยะยืนห่าง (ปล่อยเข้าระยะ 3 แล้วตีทันที) ใช้ธนู/เบ็ดสกัดระยะ 3.8 [คิดเอง] |

## 6. สรุป 3 บรรทัด
- **ทำอะไร:** วางแผนทีม 2v1/2v2/รุม/ขนาบ/ล่อ/เลือกเป้า และตารางแก้ทางรายคู่ต่อสู้ จากกลไก i-frames, sweep, ขวานปิดโล่, cooldown
- **ตัวเลขสำคัญ:** i-frames 10 tick (ตีสลับห่าง ≥10) · ขวานปิดโล่ 100 tick · โล่คุม 180° หน้า · สถิติ 1v1: ดาบเหล็ก 100%, หอก 0%, กระบองเดี่ยว 8–25%
- **ยังไม่ได้ verify:** ไม่มีข้อมูลจำลอง/จริงของทีมเลย (ตัวจำลอง 1v1 1 มิติ) — ทุกแผนที่ติด [คิดเอง] ต้องเทสตาม PVP_TEST_MATRIX §6
