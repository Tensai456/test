## 2. ตายเพราะอะไร (เท่าที่อนุมานได้) และ AFK เพราะอะไร

### 2.1 สาเหตุตายที่รู้ว่าเป็นคอขวดซ้ำ — กลไก + ตัวเลขวิกิ

| คอขวด | กลไก (ตัวเลขจากแล็บ/วิกิ) | ทำไมบอตเดิมพลาด | หมายเหตุ |
|---|---|---|---|
| ตกที่สูง | ตกเกิน 3 บล็อกเริ่มเสียเลือด · 23 บล็อก = 20 HP (ตายเมื่อเลือดเต็ม) ; จำลองว่า ~9% ของความสูงไม่มี tick พอวางน้ำทัน | ไม่ย่อที่ขอบ · ไม่สลับของ clutch ก่อนตก | ผลจำลอง ไม่ใช่การนับตายจริง (PROBLEM_PLAYBOOK P5) |
| ลาวา / ขุดลงตรง | ลาวา 4 HP ทุก 0.5 วิ + ไฟ → อยู่ได้ ≈2 วิ | ขุดใต้เท้า | veto มีแล้วในกฎ |
| ไม่กินตอนเลือดต่ำ | ฟื้นเลือดต้องหิว ≥18 (ฟื้นทุก 4 วิ) · หิว 0 = เสียเลือด 1 HP ทุก 4 วิ (W/Food_mechanics ผ่าน kb/WebSearch) | ไม่มี trigger กินตอน HP ต่ำจริง ๆ หรือกินช้า | P2 · `eat-to-regen` |
| อาหารทีม = 0 (s20) | หิว ≤6 วิ่งไม่ได้ | ไม่มีใครรับหน้าที่หาอาหาร ไม่ย่างก่อนกิน | P3 |
| ขุดมือเปล่า | หินมือเปล่า 7.5 วิ/บล็อก ไม่ได้ของ vs อีเต้อหิน 0.56 วิ | ขุดโดยไม่เช็กเครื่องมือ | เสียเวลา มากกว่าทำให้ตาย |
| ทะเลทรายไม่มีไม้ (s22) | ไม่มีซุงใน 32 บล็อก | วนอยู่กับที่ | เสียเวลาล้วน ไม่ตาย |
| บ้าน/เตียงข้างหลุม (s37) | เตียง/ประตูข้างหลุม >3 บล็อก | ไม่เลือกที่ตั้ง | ตกหลุมตอนกลางคืน/นอนไม่ทัน [อนุมาน] |
| ม็อบ (zombie/skeleton/creeper ฯลฯ) | ต่าง ๆ | HO ไม่บอกสัดส่วน | **ไม่มีข้อมูลสัดส่วน** |

### 2.2 AFK (ยืนนิ่ง) — สาเหตุที่เป็นไปได้
HO ระบุ "ยืน AFK" เป็นคอขวดซ้ำ · สมองเดิม = qwen3:8b + กฎ → สาเหตุที่ PROBLEM_PLAYBOOK P9 ระบุไว้:
1. เป้าหมายหาไม่เจอ (ไม่มีทรัพยากรในระยะสแกน เช่น ทะเลทราย s22)
2. pathfinder ติด
3. รอคำตอบ LLM (qwen3:8b ช้า) ระหว่างช่วงที่ควรลงมือ
4. ไม่ส่งต่อขั้นถัดไปของ ladder

ซึ่งทั้ง 4 ข้อเป็น "ตรรกะบอต" ไม่ใช่กลไกเกม · **ยังไม่รู้ว่าข้อไหนมากสุด** → ต้องแยกจาก jsonl ด้วยตัวบ่งชี้ `idleSeconds` + `action` + `last_llm_wait` (ดู §4)

## 4. ต้องรอข้อมูลศุกร์ ยืนยันอะไร (เช็กลิสต์)

| ต้องวัด | ที่มา | ใช้ตัดสินข้อเสนอ |
