# HOME_SITE — เลือกที่ตั้งบ้าน (handoff A5)

> โค้ด: `lib/home/home_site.mjs` (siteMetrics · scoreSite · bestSites · scanGrid) · เทส: `test/home_site.test.mjs` · **ยืนยันระดับจำลอง** (กริดสมมติ ยังไม่ได้สแกนโลกจริง)
> ที่มา: กฎ jing "บ้านต้องอยู่พื้นราบปลอดภัย" · ปัญหาสมองเดิม s37 = ทำบ้าน/เตียงข้างหลุม (handoff §1)

## 1. ตัดทิ้งทันที (ห้ามสร้าง)
| เงื่อนไข | เหตุผล |
|---|---|
| ลาวา / น้ำ / magma / ผงหิมะ / กระบองเพชร / พุ่มเบอร์รี ในกรอบบ้านหรือขอบ 3 บล็อก | ไฟ/จม/ติด/เสียเลือด (kb/hazards/damage-blocks, powder-snow-freezing) |
| ขอบรอบบ้านมีจุดต่ำกว่าพื้น ≥3 บล็อก | หลุม/หน้าผา = ตกตาย (ดาเมจตก > 3 บล็อก — kb/movement) · ปัญหา s37 |
| พื้นในกรอบต่างระดับ >3 | ไม่ราบ (กฎ jing) — ต้องปรับพื้นเยอะ |
| กรอบหลุดพื้นที่ที่สแกน / ชังก์ไม่โหลด | ไม่รู้ = ไม่เลือก |

## 2. คะแนน (ผ่านข้อ 1 แล้ว)
`100 − งานขุด/ถม × 2 − หน้าผาสูงชิดบ้าน × 3 + ต้นไม้ในรัศมี 16 × 0.8 (สูงสุด 30) + หินในรัศมี 16 × 0.5 (สูงสุด 30) − ระยะจากบอต × 0.05`
- น้ำหนักทั้งหมด = เกณฑ์แล็บ [คิดเอง] ปรับจากข้อมูลศุกร์ได้
- หน้าผาสูง ≥4 ชิดบ้าน = มืด ม็อบโดดลงหลังคาได้ จึงหักคะแนน (ไม่ตัดทิ้ง)

## 3. ใช้กับบอตจริง
```js
import { scanGrid, bestSites } from './mc-lab/lib/home/home_site.mjs';
const { grid, origin } = scanGrid(bot, Vec3, { r: 40 });           // สแกนผิวรอบตัว 81×81 (ครั้งเดียว)
const [best] = bestSites(grid, { w: 11, l: 13, from: { x: 40, z: 40 } });   // แบบบ้าน 9×11 + ชายคา 1 รอบ
const corner = { x: origin.x + best.x0, y: best.floorY + 1, z: origin.z + best.z0 };
// → tidyPlan (ปรับพื้น) → planActions/runBuild (สร้าง) — docs/MINEFLAYER_INTEGRATION.md §5
```
- `scanGrid` ไล่ `blockAt` ลงจาก y120 → ช้า (81×81×≤80 ครั้ง) [ไม่แน่ใจ: เวลาจริงบนเซิร์ฟ] · ข้ามหญ้า/ดอกไม้ (ไม่ใช่ผิวจริง)

## 4. เทส (กริดสมมติ 40×40)
- ซ้ายราบมีต้นไม้ · กลางมีรอยแยกลึก 9 บล็อก · ขวาบนมีลาวา · ล่างขวาเนินชัน → อันดับ 1 อยู่ฝั่งต้นไม้ ไม่ทับรอยแยก/ลาวา/เนิน ✅
- กรอบที่ขอบชนรอยแยก และกรอบทับลาวา → ตัดทิ้ง ✅
