# เกิดในเนเธอร์ตามไบโอม

<!-- สร้างอัตโนมัติโดย scripts/split_kb.mjs จาก docs/wiki/spawning.md · ห้ามแก้มือ -->
> W = https://minecraft.wiki/w/ (Mob_spawning, Spawn_limit, Tutorial:Spawn-proofing, Light, Slime, Swamp_Hut, Witch, Nether_Fortress, Ocean_Monument, Pillager_Outpost, Patrol, Phantom, Insomnia, Drowned, Zombie, Spider_Jockey, Chicken_Jockey, Skeleton_Horse, Monster_Spawner, Wandering_Trader, Enderman) · ข้อมูลจากสรุปผลค้นหา ไม่ได้เปิดหน้าเต็ม · ค่าที่ซ้ำกับ kb เดิม (light-levels, moon-slime, phantom, monster-room) ไม่ลงซ้ำ ลงเฉพาะส่วนที่เพิ่ม

| ไบโอม | น้ำหนัก (Java) | แหล่ง |
|---|---|---|
| Nether Wastes | zombified piglin 100/168, ghast 50/168, piglin 15/168, magma cube 2/168, enderman 1/168 | W/Mob_spawning, W/Nether_Wastes |
| Soul Sand Valley | ghast 50/71, skeleton 20/71, enderman 1/71 (ghast สำเร็จ 5% ของความพยายาม) | W/Soul_Sand_Valley |
| Basalt Deltas | magma cube 100/140, ghast 40/140 | W/Basalt_Deltas |
| Crimson Forest | hoglin 9/15, piglin 5/15, zombified piglin 1/15 | W/Crimson_Forest |
| Warped Forest | enderman พบบ่อย; มอบเป็นศัตรูอื่นไม่เกิดตามธรรมชาติ | W/Warped_Forest |
| แสงของ enderman | ≤7 ในเนเธอร์ (Overworld/End ต้อง 0) | W/Enderman |

บอตควร: Warped Forest ปลอดภัยที่สุดจากศัตรูทั่วไปแต่ห้ามมองตา enderman; Soul Sand Valley ระวัง ghast + skeleton; Basalt Deltas ระวัง ghast; กลางที่โล่งใน Wastes เจอ ghast ได้.
ตัดสินผล: เกณฑ์แล็บ — ชนิดมอบที่เจอในไบโอมต้องอยู่ในตารางนี้ ถ้าไม่ตรง (และไม่ใช่โครงสร้าง) บันทึกเป็นผิดปกติ.
