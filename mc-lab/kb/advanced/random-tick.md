# การโตของพืช (random tick)

<!-- สร้างอัตโนมัติโดย scripts/split_kb.mjs จาก docs/wiki/advanced.md · ห้ามแก้มือ -->
> W = https://minecraft.wiki/w/ · Java ปัจจุบัน · ข้อความย่อ WebSearch

- เกมสุ่มเลือกบล็อก **3 บล็อกต่อ subchunk (16×16×16) ต่อ game tick** (gamerule random_tick_speed = 3) — ไม่ใช่ "ต่อวินาที" อย่างที่ Gemini เขียน (W/Random_Tick, W/Tick)
- พืช/หญ้า/ใบไม้ร่วงอัปเดตเฉพาะในระยะจำลอง (simulation distance) รอบผู้เล่น → บอตอยู่ไกลฟาร์ม = พืชไม่โต

บอตควร:
- ฟาร์มต้องอยู่ใกล้ที่บอตใช้เวลาส่วนใหญ่ (บ้าน) · ไม่งั้นพืชไม่โต
- ประเมินเวลาโต: ใช้อัตราจาก kb/farming (ต่อ random tick) × 3/4096 ต่อ tick ต่อบล็อก [คิดเอง: สูตรประมาณ]

ตัดสินผล: ปลูกฟาร์มห่างบ้าน >128 บล็อก แล้วคาดว่าจะโต = ผิด (เกณฑ์แล็บ [ไม่แน่ใจ: ระยะ simulation distance ของเซิร์ฟ])
