# ข้อมูลเกมแบบ JSON (data pack)

<!-- สร้างอัตโนมัติโดย scripts/split_kb.mjs จาก docs/wiki/advanced.md · ห้ามแก้มือ -->
> W = https://minecraft.wiki/w/ · Java ปัจจุบัน · ข้อความย่อ WebSearch

- loot table, การสร้างโลก, สูตรคราฟต์ อยู่ในไฟล์ JSON แก้ด้วย data pack ได้ (แล็บเราใช้ minecraft-data ซึ่งดึงจากข้อมูลชุดเดียวกัน) · "HP ม็อบอยู่ใน JSON" ตามที่ Gemini เขียน [ไม่แน่ใจ] — ไม่ได้ยืนยัน

บอตควร: ถ้าเซิร์ฟใช้ data pack ที่แก้สูตร/ดรอป → รัน `scripts/gen_catalog.cjs` ใหม่ไม่ช่วย (minecraft-data = วานิลลา) ต้องอ่านจาก data pack ของเซิร์ฟเอง
