# ความยากตามพื้นที่ (โลกยิ่งเก่า ม็อบยิ่งโหด)

<!-- สร้างอัตโนมัติโดย scripts/split_kb.mjs จาก docs/wiki/advanced.md · ห้ามแก้มือ -->
> W = https://minecraft.wiki/w/ · Java ปัจจุบัน · ข้อความย่อ WebSearch

- ค่า 0.00–6.75 คิดจาก ระดับความยาก + เวลาที่ผู้เล่นอยู่ใน chunk (inhabited time) + จำนวนวันของโลก + ข้างขึ้นข้างแรม (เต็มดวงมีผลมาก) (W/Difficulty)
- ผลต่อม็อบ: ใส่เกราะ/อาวุธเอนชานต์บ่อยขึ้น · Easy/Normal ถ้ามีเกราะ: 2/3/4 ชิ้น = 75/56/42% · Hard 90/81/73% (W/Difficulty)
- **ซอมบี้พังประตูไม้/ทองแดงได้เฉพาะ Hard** (ความสามารถพังประตู = (10×CRD)% แต่พังจริงเฉพาะ Hard) — Gemini เขียนว่า "พังง่ายขึ้นตามพื้นที่" ไม่ครบ (W/Zombie)

บอตควร:
- **โลก s39 รันมา 100+ วันในเกม และบอตอยู่ที่บ้านเดิมนาน → ค่าความยากตรงนั้นสูง** → คาดว่าม็อบรอบบ้านจะใส่เกราะ/อาวุธบ่อยกว่าโลกใหม่ → เกณฑ์ "ถูกรุม" และการเลือกสู้/หนีควรเข้มขึ้นในโลกเก่า [คิดเอง]
- คืนพระจันทร์เต็มดวง = ระวังเป็นพิเศษ
- เซิร์ฟ Hard: ประตูไม้กันซอมบี้ไม่ได้ → ใช้ประตูเหล็ก (ต้องใช้ปุ่ม/แผ่นกด)

ตัดสินผล: เทียบสถิติตาย/ชม. โลกใหม่ vs โลกเก่า (s39) — ถ้าโลกเก่าตายบ่อยกว่าแม้ทักษะเท่ากัน = ผลจากความยากพื้นที่
