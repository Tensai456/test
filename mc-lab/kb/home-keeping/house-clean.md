# เก็บกวาดในบ้าน (บล็อกที่บอตวางมั่ว + ของทิ้งพื้น — กติกา jing)

<!-- สร้างอัตโนมัติโดย scripts/split_kb.mjs จาก docs/wiki/home-keeping.md · ห้ามแก้มือ -->
> W = https://minecraft.wiki/w/ · โค้ด: `lib/home/home_keep.mjs` (sortPlan · tidyPlan · stashPlan · fitInWindow · createHomeMeter) · ทำเฉพาะตอนว่าง/ปลอดภัย (รอเผา, รอเช้า) — ภัยทุกอย่างมาก่อน

- ตอนบ้านเรียบร้อย: `bot.brain.snapshotHouse({x0,y0,z0,x1,y1,z1})` = จำแบบบ้าน (ในกล่องบ้าน)
- ตรวจ: `bot.brain.houseCheck()` → `stray` (บล็อกเกินในที่ที่ควรว่าง → ขุดออก เก็บเข้าหีบ) · `missing` (ผนัง/พื้นหาย → วางคืนชนิดเดิม) · `items` (ของตกพื้นในบ้าน → เก็บ แล้วจัดลงหีบตามหมวด)
- ของใช้ที่เพิ่มเองไม่นับว่ามั่ว: คบเพลิง ตะเกียง หีบ ถัง เตา โต๊ะคราฟต์ เตียง ป้าย กรอบ พรม กระถาง
- เป็นขั้นแรกของแผน home_keep (ไม่ใช่กฎฉุกเฉิน) · ทางเดิน/ประตูถูกขวาง = กฎ entrance-blocked แยก (ด่วนกว่า)
- แบบบ้านเปลี่ยน (ต่อเติม) → ถ่าย snapshot ใหม่หลังสร้างเสร็จ ไม่งั้นส่วนต่อเติมจะถูกนับเป็นบล็อกมั่วแล้วโดนรื้อ ⚠

ตัดสินผล: houseCheck ต้อง clean ภายในรอบว่างถัดไป (เกณฑ์แล็บ)
