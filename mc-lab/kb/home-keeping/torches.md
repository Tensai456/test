# ปักคบเพลิงเพื่อไม่ให้ม็อบเกิด (กติกา jing)

<!-- สร้างอัตโนมัติโดย scripts/split_kb.mjs จาก docs/wiki/home-keeping.md · ห้ามแก้มือ -->
> W = https://minecraft.wiki/w/ · โค้ด: `lib/home/home_keep.mjs` (sortPlan · tidyPlan · stashPlan · fitInWindow · createHomeMeter) · ทำเฉพาะตอนว่าง/ปลอดภัย (รอเผา, รอเช้า) — ภัยทุกอย่างมาก่อน

- คบเพลิงแสง 14 ลด 1 ต่อบล็อก (ระยะ taxicab รวมแนวตั้ง) → ครอบคลุม 13 บล็อก · ม็อบศัตรูเกิดได้เฉพาะ block light 0 (+ sky light ≤7) (W/Light, W/Mob_spawning, W/Tutorial:Spawn-proofing)
- `torchPlan(heights, floorY, { torches, keep })`: ปูตาข่ายเพชร (เวกเตอร์ 13,14 / 14,−13 — ส่วนครอบปูเต็มพอดี 365 ช่อง/ดวง) แล้วเก็บตกจุดมืดที่เหลือ · ไม่รื้อดวงเดิม · ไม่ปักในพื้นที่เว้น
- **เขตบ้าน = รัศมี ≈100 บล็อก** (กติกา jing · `HOME_RADIUS`) → พื้นเรียบ 201×201 ต้องปัก **≈141 ดวง** = ถ่าน/ถ่านไม้ 36 + ไม้ 36 (คบเพลิง 1 สูตร = 4 ดวง) · คำนวณ 39 ms
- ทำทีละนิด: ใกล้บ้านก่อน (ตัวเก็บตกเรียงจากใกล้ไปไกล) · ถ่านไม่พอ → ทำถ่านไม้จากซุงในเตา (kb/progression/smelting-fuel)
- ตัวอย่างเล็ก: 41×41 (มีดวงกลางแล้ว) = 8 ดวง · 81×81 = 27 ดวง
- พื้นต่างระดับมาก → ต้องเพิ่มดวง (แสงลดตามความสูงด้วย) — ตัวเก็บตกจัดการให้
- ในบ้าน: ทุกห้องต้องมีคบเพลิง (ห้องปิดไม่มีแสงฟ้า = ม็อบเกิดในบ้านได้) [คิดเอง]

ตัดสินผล: ม็อบศัตรูเกิดในรัศมีที่ปักแล้ว = ตรวจว่ามีจุด block light 0 หลุด (เกณฑ์แล็บ)
