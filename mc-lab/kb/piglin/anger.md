# อะไรทำให้โกรธ

<!-- สร้างอัตโนมัติโดย scripts/split_kb.mjs จาก docs/wiki/piglin.md · ห้ามแก้มือ -->
> W = https://minecraft.wiki/w/ · จากข้อความย่อ WebSearch (ไม่ได้เปิดทั้งหน้า) · Java ปัจจุบัน

- เปิด/ทุบ หีบ, หีบกับดัก, หีบทองแดง, หีบเอนเดอร์, กล่อง shulker, ถังไม้ (barrel), รถรางมีหีบ, เรือมีหีบ (W/Piglin)
- ขุดบล็อกทอง / แร่ทอง / gilded blackstone → piglin ในรัศมี **16 บล็อก** โกรธพร้อมกัน **ไม่ต้องเห็นตัวเรา** (W/Piglin)
- ตี piglin → ตัวรอบ ๆ โกรธทั้งกลุ่ม (W/Piglin)

บอตควร:
- ห้ามเปิดหีบ/ขุดทองถ้ามี piglin ในระยะ 16 บล็อก (veto `piglin-container`) — ล่อให้ห่างก่อน หรือเคลียร์ให้หมดก่อน
- ห้ามตี piglin ที่ยังไม่โกรธ (veto `dont-provoke`)

ตัดสินผล: เปิดหีบ/ขุดทองใกล้ piglin ≤16 แล้ว piglin โกรธ = ผิด
