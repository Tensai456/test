# ลำดับ (กติกา jing: ไม่ทำทันที)

<!-- สร้างอัตโนมัติโดย scripts/split_kb.mjs จาก docs/wiki/farm-build.md · ห้ามแก้มือ -->
> W = https://minecraft.wiki/w/ · โค้ด: `lib/home/farm_plan.mjs` (farmPlan · chooseFarmSite · FARM_STEPS) · ความรู้พืชรายชนิด: kb/farming/*

1. **gather** หาของมาก่อนให้ครบตาม `farmPlan().need` (เมล็ด ถังน้ำ ไม้ทำรั้ว ถ่านทำคบเพลิง จอบ)
2. **site** เลือกที่เหมาะ: `chooseFarmSite(heights, { keep })` — พื้นต้องขุด/ถมน้อยสุด · ใกล้บ้าน · ไม่ทับทางขึ้นบ้าน/ปากเหมือง · ชันเกิน → ข้าม
3. **clear** เคลียร์พื้นให้เรียบ (ใช้ tidyPlan ของงานบ้าน กับกรอบฟาร์ม)
4. **build** ค่อยเริ่มทำฟาร์ม: วางน้ำ → ไถ → ปลูก → ปักคบเพลิง → ล้อมรั้ว + ประตูรั้ว
- ทำหลังชุดเหล็กเสร็จ (iron_kit) — ช่วงแรกอาหารมาจากสัตว์/ขนมปังจากข้าวสาลีป่า [คิดเอง: ลำดับเทียบ IRON_RACE]

ตัดสินผล: เริ่มไถก่อนเคลียร์พื้น/ก่อนของครบ = ผิดลำดับ (เกณฑ์แล็บ)
