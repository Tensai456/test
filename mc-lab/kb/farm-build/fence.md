# รั้ว

> W = https://minecraft.wiki/w/ · โค้ด: `lib/home/farm_plan.mjs` (farmPlan · chooseFarmSite · FARM_STEPS) · ความรู้พืชรายชนิด: kb/farming/*

- รั้ว/ประตูรั้ว/กำแพง สูง 1.5 → ม็อบส่วนใหญ่กระโดดข้ามไม่ได้ · **แมงมุมปีนข้ามได้ · กระต่ายกระโดดข้ามได้** (W/Fence, W/Fence_Gate) → กระต่ายกินแครอทในฟาร์ม [ไม่แน่ใจ: กินพืชจริงไหม — W/Rabbit]
- **ทางเข้าแบบพรม (ค่าเริ่ม — jing เลือก):** รั้วธรรมดา + พรมบนหัวเสา → ผู้เล่นกระโดดขึ้นไปเหยียบได้ ม็อบขึ้นไม่ได้ (ยกเว้นกระต่าย/อูฐ) (W/Fence) · ไม่ต้องเปิด-ปิด ไม่มีประตูลืมปิด · พรม = ขนแกะ 2 → 3 ผืน
  - ⚠ pathfinder อาจคิดว่ารั้วสูง 1.5 ข้ามไม่ได้ [ไม่แน่ใจ: ต้องลองบนเซิร์ฟ] → ถ้าหาทางไม่ผ่าน ให้บอตยืนชิดแล้วกดกระโดดข้ามเองตรงจุดเข้า
  - ⚠ กระโดดลงฝั่งในให้ลงที่ทางเดิน ห้ามลงบน farmland (กลับเป็นดิน — W/Farmland)
  - จูงสัตว์ผ่านไม่ได้ (ถ้าต้องพาสัตว์เข้าออก ใช้ประตูรั้ว `entrance: 'gate'`)
- ประตูรั้ว (ตัวเลือก): ปิดก็สูง 1.5 · เดินเข้าออกแล้วปิดทุกครั้ง
- กรอบฟาร์ม = keep zone ของงานบ้าน (`farmKeepZone`) → tidyPlan/torchPlan ไม่ไปถม/ปักทับ
