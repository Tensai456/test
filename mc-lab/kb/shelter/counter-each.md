# หลบ + หาของจัดการ (ทีละตัว)

<!-- สร้างอัตโนมัติโดย scripts/split_kb.mjs จาก docs/wiki/shelter.md · ห้ามแก้มือ -->
> W = https://minecraft.wiki/w/ · ข้อความย่อจาก WebSearch · กฎ jing (7 ต.ค. 2026): **ทำที่หลบได้** แต่ต้องรู้ว่าม็อบไหนทุบบล็อกได้ · ต้องพยายามหลบ · ต้องหาของมาจัดการมันให้ได้

| ภัย | หลบยังไง | ของที่ต้องหามาจัดการ |
|---|---|---|
| ครีปเปอร์ข้างกำแพง | ได้ยินเสียงฟ่อ → ถอยไปฝั่งตรงข้ามของที่หลบ ≥4 บล็อก [คิดเอง] | ธนู (ยิงก่อนเข้าใกล้) · ซ่อมรูด้วยหินกรวดทันที |
| ซอมบี้ตีประตู (Hard) | ยืนห่างประตู ตีผ่านช่อง | **ประตูเหล็ก + ปุ่ม/คันโยก** (เหล็ก 6 ก้อน) |
| enderman ดึงบล็อก | ห้ามมองตา · ผนังหินกรวดกันได้ | ฟักทองแกะสวมหัว (กันโกรธจากการมอง) · ดาบ |
| ghast ยิงที่หลบ | อยู่หลังหินกรวด · เห็นลูกไฟ → ตีสะท้อนกลับ | ธนู · หินกรวดสำรอง ≥32 ในนรก |
| ravager | **เข้าบ้าน/ช่อง 1 บล็อก** (ravager กว้าง 2 เข้าไม่ได้ ตีไม่ถึง) · ห้ามทำที่หลบด้วยใบไม้ | ดาบ/ขวาน ตีจากข้างใน · โล่ |
| Wither | อย่าหลบในที่หลบ — ระเบิดทะลุ → **ออกไปสู้ใต้ดิน/หนี** | ดาบ Smite · ยา Regeneration · นม (ล้าง Wither) |
| silverfish (stronghold/ภูเขา) | ไม่ขุดบล็อกหินที่ขุดเร็วผิดปกติ [คิดเอง] | ดาบ · ลาวา/กรวด |

ตัดสินผล: ที่หลบโดนเจาะแล้วบอตอยู่นิ่ง >2 วิ ไม่ซ่อม/ไม่ถอย = ผิด (เกณฑ์แล็บ)
