# P4 เกิดในทะเลทราย ไม่มีไม้ (เคยเกิดใน s22)

> โหมด: **คิดอย่างเดียว ยังไม่ลงมือ** · ข้อมูลจาก minecraft.wiki (ผ่าน WebSearch, Java ปัจจุบัน) · ทดสอบจริงอีก ~3 วัน
> ตัวจำลอง (`lib/`) ใช้แค่คิดตัวเลขกลไก (ดาเมจตก, เวลาขุด, ดาเมจอาวุธ) **ไม่ใช้ % ชนะ/รอด ตัดสินใจ** (ดู SIM_RESULTS §4)
> รูปแบบต่อข้อ: **อาการ** (บอตวัดได้) → **สาเหตุ** → **แก้** → **ตัวเลข+แหล่ง** → **ตัดสินผล** (ใช้กับการแย้งของผู้ฝึกงาน) → **เทสจริง**
> ที่มาของปัญหา = คอขวดสมองเดิมใน handoff (704 ตาย/166 ชม.) · ข้อที่ไม่ใช่กลไกเกม (เช่น AFK) ระบุว่า "ตรรกะบอต" ไม่ใช่วิกิ

- **อาการ:** ในระยะ 32 บล็อกไม่มีซุงเลย + biome เป็นทะเลทราย
- **สาเหตุ:** ทะเลทรายไม่มีต้นไม้
- **แก้:** ① ทุบพุ่มไม้แห้ง (dead bush) ด้วยมือ = ได้ไม้ (stick) **ใช้ทำเครื่องมือ/เป็นเชื้อเพลิงได้ แต่ทำแผ่นไม้ไม่ได้** ② ถ้าเจอหมู่บ้าน → ใช้เป็นฐาน (มีไม้ เตียง อาหาร) ③ ถ้าไม่มี → เดินทางตรงไปทางเดียวจนเจอ biome อื่นที่มีต้นไม้ จดจุดเกิดไว้ (ห้ามเดินวน)
- **ตัดสินผล:** ไม่มีซุงในระยะ 32 บล็อก + ยืนอยู่ที่เดิมหรือเดินวน **เกิน 120 วิ** = ผิด · เดินออกทางตรงหรือมุ่งไปหมู่บ้าน = ถูก
- **เทสจริง:** โลกที่เกิดในทะเลทราย → เวลาจนได้ซุงท่อนแรก
