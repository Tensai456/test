# P9 ยืนนิ่ง AFK (ตรรกะบอต ไม่ใช่กลไกเกม)

> โหมด: **คิดอย่างเดียว ยังไม่ลงมือ** · ข้อมูลจาก minecraft.wiki (ผ่าน WebSearch, Java ปัจจุบัน) · ทดสอบจริงอีก ~3 วัน
> ตัวจำลอง (`lib/`) ใช้แค่คิดตัวเลขกลไก (ดาเมจตก, เวลาขุด, ดาเมจอาวุธ) **ไม่ใช้ % ชนะ/รอด ตัดสินใจ** (ดู SIM_RESULTS §4)
> รูปแบบต่อข้อ: **อาการ** (บอตวัดได้) → **สาเหตุ** → **แก้** → **ตัวเลข+แหล่ง** → **ตัดสินผล** (ใช้กับการแย้งของผู้ฝึกงาน) → **เทสจริง**
> ที่มาของปัญหา = คอขวดสมองเดิมใน handoff (704 ตาย/166 ชม.) · ข้อที่ไม่ใช่กลไกเกม (เช่น AFK) ระบุว่า "ตรรกะบอต" ไม่ใช่วิกิ

- **อาการ:** ตำแหน่งขยับ < 1 บล็อก **และ** กระเป๋าไม่เปลี่ยน **และ** ไม่ได้ขุด วาง ตี หรือกิน นานเกิน 30 วิ (ตอนกลางวันโดยไม่มีเหตุ)
- **สาเหตุที่เป็นไปได้:** เป้าหมายหาไม่เจอ (ไม่มีทรัพยากรในระยะสแกน) · pathfinder ติด · รอคำตอบจาก LLM · ยังไม่ได้ส่งต่อไปขั้นถัดไปของ ladder
- **แก้:** ① watchdog: ยืนนิ่ง 30 วิ → บังคับเลือกเป้าหมายจาก ladder ที่ยังไม่สำเร็จ ② หาไม่เจอ → ขยายระยะสแกน 32 → 64 → 128 บล็อก แล้วออกสำรวจทางตรง ③ pathfinder ติด 3 ครั้ง → ลบเป้าหมายนั้น
- **ตัดสินผล:** เข้าเงื่อนไขอาการ + ไม่มีเหตุยกเว้น (นอน, รอเตา, หลบฝน/มืดในบ้าน) = ผิด
- **เทสจริง:** นาทีที่ยืนนิ่งต่อชั่วโมงของรุ่นพี่ เทียบกับสมองใหม่
