# ยังไม่ยืนยัน

<!-- สร้างอัตโนมัติโดย scripts/split_kb.mjs จาก docs/wiki/biomes.md · ห้ามแก้มือ -->
> W = https://minecraft.wiki/w/ · ข้อมูลจาก snippet ค้นหาเท่านั้น (โควต้าค้นหาหมดกลางทาง) · ช่องที่ไม่มีแหล่ง = [ไม่แน่ใจ] · คะแนนบ้าน 1-5 เป็นดุลยพินิจแล็บ ไม่ใช่ตัวเลขวิกิ

- คะแนนบ้าน 1-5 ทุกกลุ่มเป็นดุลยพินิจ ไม่ใช่ข้อมูลวิกิ
- ชนิดไม้ที่เก็บได้ในจังเกิล (ยืนยันแค่ว่ามีต้นจังเกิล/โกโก้), นมแก้พิษ bogged, ม้า/ลาขี่ได้
- jagged/stony peaks รายละเอียด; อาหารรายไบโอม (taiga, desert, nether); ม็อบศัตรูเฉพาะ plains/forest
- การขนาด/ความหายากสัตว์ใน snowy biome (นอกจาก stray); beach/river ค่า spawn Java ละเอียด
- ตัวเลขทั้งหมดมาจาก snippet ไม่ได้เปิดหน้าเต็ม
