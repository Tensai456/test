# ที่ราบ/ป่า (plains, forest, birch, dark forest)

<!-- สร้างอัตโนมัติโดย scripts/split_kb.mjs จาก docs/wiki/biomes.md · ห้ามแก้มือ -->
> W = https://minecraft.wiki/w/ · ข้อมูลจาก snippet ค้นหาเท่านั้น (โควต้าค้นหาหมดกลางทาง) · ช่องที่ไม่มีแหล่ง = [ไม่แน่ใจ] · คะแนนบ้าน 1-5 เป็นดุลยพินิจแล็บ ไม่ใช่ตัวเลขวิกิ

| หัวข้อ | ข้อมูล |
|---|---|
| ไม้ | Plains: โอ๊คเกิดบางต้น 1/3 ใหญ่ 1/20 มีรังผึ้ง (W/Plains); Forest: โอ๊ค+เบิร์ช (W/Forest); Birch Forest ไม่มีโอ๊ค (W/Forest) |
| อาหาร | Plains: แกะ ไก่ หมู วัว (W/Plains) |
| ม็อบพิเศษ | Plains: ม้า/ลา (W/Plains); Forest: หมาป่า variant woods ตั้งแต่ 1.20.5; Birch/Dark Forest ไม่มีหมาป่า (W/Forest) |
| โครงสร้าง | Plains: หมู่บ้านไม้โอ๊ค, ด่านพิลเลเจอร์ (W/Plains) |
| Pale Garden | ตัวแปรหายากของ dark forest (W/Pale_Garden) |
| บ้าน | 4/5 ดุลยพินิจ: พื้นเรียบ ไม้/สัตว์หาง่าย (ไม่ใช่ข้อมูลวิกิ) |
- Forest ครอบ ~12% ของโอเวอร์เวิลด์ พบบ่อยสุด (W/Forest)
- ภัยเฉพาะไบโอม (ม็อบศัตรู/ค่า spawn ละเอียด) [ไม่แน่ใจ ไม่ได้ค้น]; Plains มี zombie horse กลางคืน (W/Plains)

บอตควร: ใช้เป็นฐานเริ่มต้น; ใช้ไม้โอ๊ค/เบิร์ชใน forest; ระวังหมาป่าแบบป่าถ้าโจมตี [ไม่แน่ใจ]
ตัดสินผล: เกณฑ์แล็บ ผ่านเมื่อบอตระบุไบโอมได้ถูกจาก F3/ข้อมูลเกม (ไม่ใช่ตัวเลขวิกิ)
