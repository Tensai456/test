# วัฏจักรกลางวัน-กลางคืน

> W = https://minecraft.wiki/w/ (อ้างเป็น W/Page) · ค่าที่ไม่มีแหล่งอ้าง = [ไม่แน่ใจ] · "เกณฑ์แล็บ" = threshold ที่แล็บตั้งเอง ไม่ใช่ค่าจากวิกิ

| ช่วง | tick | อ้างอิง |
|---|---|---|
| 1 วัน | 24000 tick | W/Daylight_cycle |
| กลางวัน | 0–12000 (noon 6000) | W/Daylight_cycle |
| พระอาทิตย์ตก/dusk | เริ่ม 12000, dusk 12610 | W/Daylight_cycle |
| กลางคืน | 13000–23000 (midnight 18000) | W/Daylight_cycle |
| รุ่งอรุณ | 23000–24000 | W/Daylight_cycle |

บอตควร: อ่าน `time of day` mod 24000 แล้วจัดเป็นช่วงตามตาราง
ตัดสินผล (เกณฑ์แล็บ): ถือ "อันตราย" เมื่อ tick ∈ [12000, 23999] หรือมีพายุ; ถือ "ปลอดภัยบนผิวดิน" เมื่อ 0–11999 และไม่ฝนตก
