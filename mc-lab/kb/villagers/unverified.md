- งบค้นหาหมดกลางทาง: ไม่ได้ตรวจ HP/ดรอป/วิธีสร้าง iron golem, ขั้นตอน+เวลารักษา zombie villager, เวลา grow-up/cooldown ของการเพาะ, รายการที่ขายมรกตได้, ตัวเลขจำนวนเตียงที่ใช้ได้จริง, ป้องกัน siege
- เงื่อนไข siege (20 เตียง/ฟ้าผ่า) อาจเป็นของ Bedrock; Java snippet ของ iron golem ยังเป็น Java vs Bedrock คละ
- ช่วงราคา Mending 10–38 เป็นการคำนวณจากสูตรใน snippet ไม่ใช่ตัวเลขตรงจากหน้า
- ตัวเลขแล็บทั้งหมด (60 วินาที, 5 นาที, ≥1 มรกต ฯลฯ) เป็นเกณฑ์แล็บ ไม่ใช่ค่าวานิลลา
